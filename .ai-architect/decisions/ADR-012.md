# ADR-012: Publicación controlada

**Estado:** aceptado.

## Contexto
El repositorio ya sirve una versión pública operativa.

## Decisión
Trabajar en rama independiente, revisar cambios y gates, publicar solo versión aprobada y verificable; conservar línea base y procedimiento de reversión.

## Consecuencias
- Beneficio: Continuidad de servicio
- Coste: Requiere disciplina de release

## Validación
Commit candidato identificado, CI y revisión registrados, HTTP y recorridos postpublicación comprobados; rollback documentado.

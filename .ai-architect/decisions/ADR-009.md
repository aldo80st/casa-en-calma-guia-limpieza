# ADR-009: GitHub Pages

**Estado:** aceptado.

## Contexto
La página pública y la portada responden por HTTPS.

## Decisión
Mantener GitHub Pages, mismo enlace y recursos estáticos; sin exponer infraestructura interna.

## Consecuencias
- Beneficio: Operación económica y desacoplada
- Coste: Caché y latencia de publicación

## Validación
Versión pública y recursos comprobados por HTTP; navegación directa compatible con Pages.

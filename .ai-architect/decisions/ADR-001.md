# ADR-001: Arquitectura estática modular

**Estado:** aceptado.

## Contexto
La versión vigente concentra HTML, estilos, datos y lógica; no se necesita un backend.

## Decisión
Mantener una aplicación web estática modular, sin patrón arquitectónico formal ni servicios de ejecución adicionales.

## Consecuencias
- Beneficio: Simplicidad y continuidad del alojamiento
- Coste: Disciplina de separación de módulos

## Validación
El catálogo y la lógica funcionan en el navegador sin API propia.

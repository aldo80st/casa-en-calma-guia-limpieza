# ADR-002: Frontend nativo

**Estado:** aceptado.

## Contexto
La interfaz existente usa HTML, CSS y JavaScript.

## Decisión
Usar HTML semántico, CSS y módulos ES de JavaScript nativo; no incorporar framework sin evidencia y nueva decisión.

## Consecuencias
- Beneficio: Dependencias mínimas y portabilidad
- Coste: Componentes y estado requieren convenciones explícitas

## Validación
Los recorridos principales funcionan en navegadores modernos y sin framework.
